## Problem

The legacy storefront had duplicated UI logic and inconsistent components, which slowed down feature delivery and caused defects—especially on mobile. Performance regressions increased bounce rate and the codebase was hard to maintain.

## Solution

I helped rebuild critical views in Vue 3 with a component-driven architecture. We extracted patterns (cards, lists, forms) into reusable components and improved network workflows with clearer loading and empty states. Vite tooling shortened feedback loops and our REST API integration used typed helpers.

## Impact/Results

- Rebuilt UI into reusable components, reducing duplicated code.
- Fewer UI defects after standardizing patterns and states.
- Mobile performance improved through image optimization, route-level code-splitting, and careful use of transitions.

## Stack

- Vue.js 3, Vite
- REST APIs
- Tailwind CSS for utility-first styling
- Jest/Vitest for component tests (where applicable)
