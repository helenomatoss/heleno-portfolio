## Problem

The app suffered from slow cold starts and janky navigation, which eroded user confidence. Several UI bugs were reported on smaller Android devices.

## Solution

Profiled startup and reduced non-critical work until after initial render. Improved route transitions using Ionic’s Nav with smarter preloading and ensured list virtualization for large data views. Fixed layout issues with responsive utilities.

## Impact/Results

- Resolved UI bugs in forms and tab views.
- Faster startup visible in devtools and user feedback.
- Smoother navigation with fewer frame drops.

## Stack

- Ionic + Angular (Capacitor)
- TypeScript, RxJS
- Android Studio for device testing
