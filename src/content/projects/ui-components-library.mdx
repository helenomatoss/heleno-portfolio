## Problem

Across my personal projects, I often rebuilt the same UI primitives with small differences—leading to repeated effort and inconsistency.

## Solution

I created a small component library in Vue 3 with Tailwind, including buttons, dialogs, forms, and toasts. I emphasized a11y with ARIA attributes, keyboard nav, and focus management. Each component includes usage examples and props documentation.

## Impact/Results

- Faster prototyping and more consistent UI across projects.
- Better a11y through consistent patterns and testing.

## Stack

- Vue.js 3
- Tailwind CSS
- Vite for dev/build
